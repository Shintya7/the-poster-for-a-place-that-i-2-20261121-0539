A travel poster for Velmara, a place that does not exist: a dusk seascape where the sea turns to glass beneath a low golden sun, watched over by a lighthouse on a basalt headland. Drawn with Python + PIL (draw.py); main.ts copies entry.png to /output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
